# Firebase Studio

This is a NextJS starter in Firebase Studio.

To get started, take a look at src/app/page.tsx.

## Seeding the Database

This project is configured to work with a Firestore database. To get started with sample data, you need to seed your database.

**To run the seed script, execute the following command in your terminal:**

```bash
npm run seed
```

This will populate your Firestore with sample users, patients, encounters, and other necessary data to make the application fully functional.
